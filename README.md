# 简约音乐 · SimpleMusic

一个 Android 音乐播放器（包名 `com.simple.music`，minSdk 24 / targetSdk 35）。

> **本仓库只用于发布安装包与更新说明，不存放源码。**

## 下载安装

前往 [最新版本](../../releases/latest) 下载 `SimpleMusic-v<版本>-release.apk`，传到手机上点击安装即可
（首次安装需要允许「安装未知应用」）。

## 应用内更新

应用内「设置 → 检查更新」（或「关于」页的同名入口）会读取本仓库的 Releases 信息比对版本号：

- 发现新版本时弹窗展示更新说明，可直接在应用内下载并安装
- 下载网络不稳时会**自动切换备用线路上重试**，避免卡在很小的进度不动
- 下载完成后会**校验签名**——与已安装应用签名不一致的包**一律拒装**
- 没有「安装未知应用」权限时，会改为打开浏览器下载页由你手动安装
- 检查更新**只读取公开的版本信息，不上传任何数据**

> **发版约定**（维护者注）：Release 的 tag 必须形如 `v<versionCode>`（如 `v231`），
> 标题填展示版本名（如 `1.27.0`），正文即更新说明，APK 作为资产上传。
